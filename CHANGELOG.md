# Changelog

Este arquivo registra versões publicadas do Alexandria. Ele é atualizado pela
PR de release a partir dos commits convencionais aceitos em `main`.

`version.txt` e `.release-please-manifest.json` formam a fonte de verdade da
versão; um manifesto vazio representa apenas o bootstrap anterior à primeira
release pública.
