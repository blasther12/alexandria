# Guia de leitura — AI Engineer

1. **Artificial Intelligence: A Modern Approach** (capítulos selecionados) para
   enxergar IA além de LLMs.
2. **Deep Learning** para fundamentos matemáticos conforme a lacuna.
3. **Hands-On Large Language Models** para modelos e aplicações com intuição.
4. **Build a Large Language Model (From Scratch)** para remover a magia dos
   internals.
5. **AI Engineering** para avaliação, serving, dados e operação.
6. **Designing Data-Intensive Applications** para o sistema que cerca o modelo.

Construa em paralelo o [projeto RAG](../../projects/10-rag.md). Uma leitura sobre
modelo só é incorporada quando muda dataset, avaliação, arquitetura, segurança
ou custo de forma mensurável.
