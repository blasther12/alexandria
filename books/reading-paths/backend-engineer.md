# Guia de leitura — Backend Engineer

1. **Livro idiomático da linguagem:** Fluent Python, Effective TypeScript,
   Learning Go ou Kotlin in Action.
2. **SQL Performance Explained:** índices e planos antes de abstrações de ORM.
3. **Release It!:** falhas de dependência, estabilidade e vida em produção.
4. **Designing Data-Intensive Applications:** armazenamento, replicação e streams.
5. **Enterprise Integration Patterns:** vocabulário para comunicação assíncrona.
6. **Understanding Distributed Systems:** consolidação operacional.

A ordem segue o caminho de uma requisição: runtime → dados → dependências →
distribuição. Após cada obra, evolua os [projetos 1–9](../../projects/README.md) e
meça um modo de falha.
