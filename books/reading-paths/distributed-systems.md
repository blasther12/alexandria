# Guia de leitura — Sistemas Distribuídos

```text
Understanding Distributed Systems
        ↓
Designing Data-Intensive Applications
        ↓
Distributed Systems — van Steen & Tanenbaum
        ↓
Database Internals
        ↓
Release It! + papers/RFCs do sistema estudado
```

O primeiro livro oferece o mapa; DDIA ensina trade-offs de sistemas de dados; o
texto acadêmico formaliza mecanismos; Database Internals aproxima storage e
coordenação. Release It! devolve tudo aos incidentes e à operação.

Não espere terminar para praticar. Simule atraso, perda, duplicação, reorder,
crash e clock skew. Implemente um algoritmo educacional e depois leia a
documentação de uma implementação real para descobrir o trabalho omitido.
