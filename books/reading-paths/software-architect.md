# Guia de leitura — Software Architect

1. **Fundamentals of Software Architecture** — atributos, estilos e método.
2. **Domain-Driven Design** — limites fundamentados no problema.
3. **Designing Data-Intensive Applications** — realidade dos dados e falhas.
4. **Release It!** — comportamento sob operação.
5. **Building Evolutionary Architectures** — mudança guiada e fitness functions.
6. **Software Architecture: The Hard Parts** — dimensões de trade-off entrelaçadas.
7. **Monolith to Microservices** — evolução incremental, quando justificada.

Para cada livro, revise o mesmo sistema e registre o que mudaria — e o que não
mudaria. Uma arquitetura madura inclui gatilhos de evolução, não apenas estado
final desejado.
