# Codex

Um **Codex** é um guia de estudo completo, não necessariamente um diretório sob
`codex/`. Os Codices vivem junto de seus domínios para que conteúdo, exercícios
e referências evoluam no mesmo contexto; este arquivo é apenas o catálogo.

## O que torna um guia um Codex

- posição explícita no Atlas;
- pré-requisitos e resultado de aprendizagem;
- mecanismo e internals, não apenas interface;
- decisões, alternativas, falhas e limites;
- exemplos e prática em níveis progressivos;
- referências primárias verificadas;
- navegação para conhecimento anterior e posterior.
