# Ferramentas do desenvolvedor

Ferramentas valem pelos modelos mentais que tornam trabalho reproduzível. Esta
área começa com [Git](git/README.md) para história e colaboração e [Vim](vim/README.md)
para edição composável.

| Ferramenta | Modelo central | Evidência de domínio |
| --- | --- | --- |
| Git | grafo imutável de snapshots + refs móveis | recuperar e explicar uma história |
| Vim | linguagem `operator + motion/text object` | editar por intenção e repetir mudanças |

O roadmap inclui shell, debuggers, profilers, build systems, IDE internals e
automação local. Uma nova ferramenta deve entrar por uma capacidade, não por
popularidade.
