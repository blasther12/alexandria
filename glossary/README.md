# Glossário

Definições são curtas e apontam ao Codex que oferece contexto. Termos em inglês
permanecem quando são a forma mais usada na indústria.

| Termo | Definição operacional | Aprofundamento |
| --- | --- | --- |
| ACID | propriedades de transações: atomicidade, consistência, isolamento e durabilidade | [Bancos de dados](../databases/README.md) |
| Backpressure | mecanismo para impedir que produtores excedam continuamente consumidores | [Sistemas distribuídos](../distributed-systems/README.md) |
| Bounded Context | limite no qual um modelo e sua linguagem têm significado consistente | [DDD](../software-engineering/ddd/README.md) |
| CAP | resultado sobre consistência linearizável e disponibilidade durante partição de rede | [Sistemas distribuídos](../distributed-systems/README.md) |
| Codex | guia completo conectado a uma trilha, prática e fontes | [Catálogo](../codex/README.md) |
| Eventual consistency | convergência na ausência de novas atualizações, sob premissas declaradas | [Sistemas distribuídos](../distributed-systems/README.md) |
| Idempotência | propriedade em que repetir a mesma operação lógica não altera o efeito final além da primeira aplicação | [Mensageria](../messaging/README.md) |
| Invariante | condição que deve permanecer verdadeira nas transições válidas do sistema | [Engenharia](../software-engineering/README.md) |
| p99 | valor abaixo do qual ficam 99% das observações de uma distribuição | [Observabilidade](../observability/README.md) |
| RAG | geração apoiada por recuperação de evidências externas | [AI Engineering](../ai-engineering/README.md) |
| RPO | perda máxima de dados aceitável expressa em tempo | [Arquitetura](../architecture/README.md) |
| RTO | tempo máximo aceitável para restaurar um serviço | [Arquitetura](../architecture/README.md) |
| SLI | medida quantitativa de um aspecto do serviço | [Observabilidade](../observability/README.md) |
| SLO | objetivo definido sobre um SLI durante uma janela | [Observabilidade](../observability/README.md) |
| Tool | capacidade estruturada que uma aplicação ou modelo pode invocar | [Agentes](../agents/README.md) |

## Contribuindo

Não transforme o glossário em um segundo guia. Adicione somente definições que
reduzam ambiguidade entre domínios e sempre conecte à explicação principal.
