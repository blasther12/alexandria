# Library — referências externas

A Library preserva caminhos para fontes confiáveis; os Codices preservam o
contexto de aprendizagem. Uma referência entra quando possui autoria, fonte e
papel claros — nunca para aumentar uma lista.

## Catálogos

| Coleção | Conteúdo | Política |
| --- | --- | --- |
| [Livros](books.md) | catálogo e guias de leitura | autor/editor; nenhum conteúdo reproduzido |
| [Papers](papers.md) | trabalhos que fundamentam mecanismos | fonte do autor, conferência ou DOI |
| [RFCs e standards](rfcs.md) | contratos normativos | RFC Editor ou mantenedor do standard |
| [Documentação](documentation.md) | comportamento de produtos e linguagens | site oficial e versão quando necessário |
| [Cursos, artigos e vídeos](courses-and-articles.md) | explicação complementar | autor/organização reconhecida e propósito explícito |

## Hierarquia de evidência

Documentação descreve comportamento suportado; standard descreve contrato;
paper descreve hipótese e avaliação em um contexto; livro sintetiza um campo;
artigo ou vídeo pode oferecer experiência e intuição. Uma fonte não substitui a
outra.

## Verificação

Antes de aceitar um link, confirme existência, título, autores, origem e se há
uma URL canônica melhor. Não enlace cópias ilegais ou mirrors. Quando uma
afirmação depende de versão, registre a versão junto ao Codex, não apenas aqui.
