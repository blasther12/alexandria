# Livros

O catálogo canônico está em [BOOKS.md](../BOOKS.md). Os percursos vivem em
[books/reading-paths](../books/README.md). Esta página existe para manter a
navegação da Library sem duplicar metadados.

## Política

- título, autor e edição são confirmados na página oficial;
- “por que ler” descreve uma capacidade, não prestígio;
- dificuldade e ordem são orientação editorial;
- não hospedamos scans, resumos substitutivos ou trechos extensos;
- detalhes de API no livro devem ser comparados à documentação atual.
