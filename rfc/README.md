# RFCs

O catálogo canônico vive em [Library / RFCs](../library/rfcs.md). Este diretório
receberá guias de leitura e experimentos de interoperabilidade, não cópias dos
documentos.

Antes de implementar, confira status, errata e relações “Updates/Obsoletes” no
[RFC Editor](https://www.rfc-editor.org/). Use BCP 14 corretamente ao escrever
contratos normativos.
